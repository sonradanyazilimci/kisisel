# images/

Profil fotoğrafın ve portföy projelerinin görselleri buraya konur.

Akış:
1. Admin panelinde bir görsel seçtiğinde, dosya önerilen adla bilgisayarına iner (genelde İndirilenler klasörüne).
2. İnen dosyayı bu klasöre (`images/`) taşı.
3. Projeyi GitHub'a yüklerken bu klasörü de birlikte gönder.

Panelde görsel alanına yazdığın yol (`images/dosya-adi.jpg`) ile buradaki gerçek dosya adı birebir aynı olmalı, yoksa site görseli gösteremez.
